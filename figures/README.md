# Historical figures

The PNG/PDF files in this folder predate the advisor-review revision. They are
preserved as historical artifacts, including the former SC/NIST plots, and are
not regenerated or validated by the current runner. Do not cite them as results
of the revised experiments.

New figures are written only to the explicitly selected `results/...` run folder.
See ../RUN_VSCODE.md and ../ADVISOR_CHANGES.md for configurations and limitations.
